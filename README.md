# Recorriendo Colombia — MVP

Web app de estimulación semántica para personas adultas mayores, inspirada en un recorrido por ciudades de Colombia.

## Ejecutar localmente

1. Instala las dependencias con `pnpm install`.
2. Inicia el entorno de desarrollo con `pnpm dev`.
3. Abre la URL local que muestra Vite.

Para generar la versión de producción, ejecuta `pnpm build`.

## Incluido en este MVP

- Editor de viajero con tono de piel, color de ojos, cabello, tipo de cuerpo y ropa; las opciones son neutras y no representan una edad específica.
- Primer destino: Cartagena, con cinco retos de vocabulario y asociación semántica.
- Pistas, lectura de pregunta mediante el navegador, retroalimentación amable y sin tiempo límite.
- Monedas, resumen de logro, diploma y panel local de apoyo fonoaudiológico con indicadores por habilidad, métricas acumuladas, objetivos y recomendaciones de intervención.
- Persistencia de nombre y progreso en el navegador; no se envía información a terceros.
